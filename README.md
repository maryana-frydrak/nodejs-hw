# Node.js Homework - Express Server

Це мій перший проєкт на Node.js з використанням Express.

## Опис

Проєкт створений для вивчення основ бекенд-розробки:

- Налаштування середовища (ESLint, Prettier, nodemon).
- Робота зі змінними оточення (.env).
- Реалізація REST маршрутів.
- Обробка помилок.

## Як запустити

1. Клонуйте репозиторій:
   `git clone [https://github.com/maryana-frydrak/nodejs-hw]`
2. Встановіть залежності:
   `npm install`
3. Створіть файл `.env` у корені проєкту і додайте туди:
   `PORT=3000`
4. Запустіть сервер у режимі розробки:
   `npm run dev`

## Маршрути

- `GET /notes` - отримати список усіх нотаток.
- `GET /notes/:noteId` - отримати детальну інформацію про нотатку.
- `GET /test-error` - для перевірки обробки помилок.

Параметри:

tag (string): фільтрація за тегом (наприклад, ?tag=Todo).

search (string): пошук за заголовком або контентом (наприклад, ?search=hello).

Приклад запиту: 'http://localhost:3030/notes?tag=Todo&search=hello'
